# Claude Code integration

Use the canonical Agent Skill at `../../skills/ghost-feature-hunter/SKILL.md`. Copy the complete `ghost-feature-hunter` directory to `.claude/skills/ghost-feature-hunter/` for the project or `~/.claude/skills/ghost-feature-hunter/` for the user. See [Claude Code skills documentation](https://code.claude.com/docs/en/skills).

Install the Python CLI separately from the repository root with `python -m pip install -e .`. The platform note and skill use the same verification engine.
